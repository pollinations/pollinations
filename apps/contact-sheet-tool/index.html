One sheet. Many possibilities.

Arrange saved images into a captioned contact sheet. Run it here, edit the bank, or import the function into your own notebook. Rendering happens in your browser; no key needed.

Preparing local examples…

Edit or exchange the image bank

Use {"images":[{"url":"https://…","caption":"…"}]}. Up to 24 images and 16 MB of JSON. Long captions are shortened only on the sheet; the bank keeps the full text. Public media links must allow CORS. Use local files when a host blocks canvas export.

Loading a URL contacts its image host. Only share public links: do not paste keys, private or signed URLs, or personal data. PNG/JPEG/WebP/GIF/SVG uploads are embedded in exported banks. Images are decoded by the browser, never inserted as HTML.

After editing captions or URLs, press Render sheet. A load error keeps the previous sheet available.
