The working path

Three small moves.

Hermes' model wizard is interactive. Keep this page open, copy your key when the wizard asks for it, and choose a model from the live list.

01

Install Hermes

Linux, macOS, WSL2, and Termux are supported by the official installer.

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
02

Connect Pollinations

Get a key with starter credits, then launch Hermes' interactive model picker.

Get a Pollinations key ↗
hermes model
03
