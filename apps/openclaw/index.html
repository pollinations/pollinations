pollinations.ai × OpenClaw

Connect OpenClaw to the live Pollinations catalog through a single API. The Polli CLI selects compatible tool-calling text models and keeps the provider key in an environment reference.

Set up OpenClaw
Install OpenClaw using the official instructions, then log in:
npx --yes @pollinations/cli auth login
Connect it through the Polli CLI package:
npx --yes @pollinations/cli harness openclaw on
  • 🤖 Discovers live text models that support tools and chat completions.
  • 🔑 Stores the dedicated key in env.vars.POLLI_OPENCLAW_API_KEY and references it from the provider.
  • ⚙️ Use npx --yes @pollinations/cli harness openclaw status to inspect or npx --yes @pollinations/cli harness openclaw off to remove the Pollinations-owned fields.
Ask your coding agent to run the Polli CLI adapter:
npx --yes @pollinations/cli harness openclaw on

Check with npx --yes @pollinations/cli harness openclaw status; disconnect with npx --yes @pollinations/cli harness openclaw off.

Live compatible models

The adapter reads the current catalog at setup time and selects a compatible tool-calling text model dynamically. See the live catalog for current model IDs and metadata.

Switch models in OpenClaw using an ID from the live catalog.
