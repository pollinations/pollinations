# 🎭 AI 派对推理（Party Deduction）

> Pollinations Bounty #15726 · 纯静态 · pass-and-play 社交推理游戏

一台设备、一圈朋友、几轮演技较量。AI 主持人负责旁白、计时与真相揭晓，你们负责找出隐藏在人群中的叛徒。

**零构建依赖**：纯 HTML / CSS / JS，本地双击打开即可游玩，也可直接托管到 GitHub Pages。

---

## ✨ 特性

- **4–10 人轮流传机**（pass-and-play）：手机或电脑在玩家间传递，逐个查看秘密身份、逐个投票，其他玩家请自觉闭眼。
- **8 个原创场景模板**：太空飞船 🚀 / 庄园谋杀 🏰 / 海盗船 🏴‍☠️ / 魔法学院 🪄 / 西部小镇 🌵 / 吸血鬼城堡 🧛 / 机器人工厂 🤖 / 失落神庙 🗿，每局随机组合场景与秘密角色。
- **双阵营对抗**：好人（找出叛徒）vs 叛徒（隐藏身份、误导投票），各自持有秘密目标。
- **完整流程**：场景开场 → 秘密身份分发 → 讨论计时轮（60–180s 可调）→ 公开投票 → TTS 宣读投票结果 → 真相揭示 → 胜负结算。
- **AI 语音主持人**：开场白、讨论引导、投票结果、真相旁白全部语音朗读。
  - 首选：Pollinations 匿名 TTS（`GET https://gen.pollinations.ai/audio/{文本}`）
  - 兜底：浏览器 Web Speech API（`speechSynthesis`）
  - 可一键静音旁白（状态记忆）。
- **AI 文本增强（可选，BYOP）**：登录 Pollinations BYOP 后，可让 AI 生成全新场景、润色旁白；未登录或请求失败时自动降级本地模板，绝不阻塞游戏。
- **断点续玩**：游戏状态实时保存至 `localStorage`，中途关闭页面可继续。
- **精致深色主题**：派对氛围渐变、环形倒计时、动效卡片，移动端自适应。

## 🎮 游玩说明

1. **开局设置**：选择玩家数（4–10）、讨论时长（60–180 秒）、场景（随机或指定）。
2. **开场旁白**：AI 主持人介绍场景背景与阵营构成。点击「开始分发身份」。
3. **身份分发**：按提示把设备交给对应玩家 → 点「显示我的身份」查看秘密身份与目标 → 记住后点「我记住了，传给下一位」。
   - 🟢 好人：找出叛徒；🔴 叛徒：隐藏自己、误导投票。
4. **自由讨论**：进入倒计时，大家面对面讨论，结合主持人的话题提示寻找破绽。可提前结束讨论。
5. **公开投票**：轮流把设备交给每位玩家，投出最可疑的人（不能投自己）。
6. **结果宣读**：主持人朗读票数最高者身份，展示票数统计。
7. **真相与结算**：查看全员身份档案与阵营胜负，可一键「再玩一局」。

> 💡 传机时请其他玩家移开视线——身份保密是游戏乐趣的核心。

### BYOP 登录（可选增强）

- 点击设置面板的「BYOP 登录」，跳转 Pollinations 授权页，同意后自动回跳。
- API key 通过 `location.hash` 回传，**仅保存在内存 / sessionStorage，不落盘**。
- 登录后可使用「AI 生成新场景」，生成的场景会自动加入场景列表并本地持久化。

## 🚀 部署说明（GitHub Pages）

### 方式一：直接上传仓库

1. 在 GitHub 新建仓库（如 `polli-party`）。
2. 将本目录下 `index.html`、`styles.css`、`script.js`、`README.md` 全部上传到仓库根目录。
3. 仓库 `Settings → Pages`：Source 选择 `Deploy from a branch`，分支选 `main`，目录 `/ (root)`，保存。
4. 等待 1–2 分钟，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

### 方式二：本地预览

无需任何服务器，直接双击 `index.html` 即可在浏览器中完整体验（TTS 与 BYOP 功能均可用）。

## 🔒 隐私说明

- 全程纯前端运行，无后端、无追踪。
- 游戏状态、场景列表、静音偏好仅存于浏览器 `localStorage`。
- BYOP API key 仅存于内存 / `sessionStorage`，刷新页面后需重新登录。
- 语音由 Pollinations 匿名接口或浏览器本地合成，不采集个人信息。
