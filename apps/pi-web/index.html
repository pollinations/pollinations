    How it works
    
    
    
      Pi runs inside a WebAssembly sandbox with networking disabled. When it
      makes an HTTP call, the request is written to /workspace/.bridge
      and answered by this page, which adds your key and talks to
      gen.pollinations.ai. Your key never enters the sandbox.
