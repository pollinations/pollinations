What runs here, and current limits
Upstream Pi 0.87.1 runs through Wasmer’s published package and SDK 0.19.0. A supported Pi provider extension sends model HTTPS requests through the browser. Pi’s agent loop and read/write/edit/Bash tools run inside WASIX; no remote Pi process or WISP relay is required.
First startup can download over 100 MB. Use a current browser with WebAssembly threads, SharedArrayBuffer, and sufficient memory. A service worker enables isolation on static hosts and may reload the first visit. Responses are buffered per API call before Pi consumes them. Project network access and package installation are disabled; bundled Node, Bash, and core utilities work. Stopping resets the complete sandbox after exporting the project, because WASIX descendants are not Unix process groups.
The optional Computer MCP operates a separate cloud filesystem and does not control this browser or your computer. Its commands and Exa searches are paid. Public agent publishing permission is not needed.
