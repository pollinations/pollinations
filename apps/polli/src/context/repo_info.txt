# Pollinations.AI Platform Reference

## Architecture
```
gen.pollinations.ai (unified proxy) → enter.pollinations.ai (auth/billing) | text.pollinations.ai (text backend)
```
Repo: `pollinations/pollinations` (main branch) | Discord: guild `885844321461485618`
Docs: https://gen.pollinations.ai/docs | Monitor: https://model-monitor.pollinations.ai

## API — gen.pollinations.ai (the ONLY public URL)

Endpoints: `/v1/chat/completions` POST (OpenAI-compatible, RECOMMENDED) | `/text/{{prompt}}` GET | `/image/{{prompt}}` GET | `/audio/{{text}}` GET | `/v1/models` GET | `/text/models` GET (w/ pricing) | `/image/models` GET (w/ pricing) | `/account/balance|profile|usage` GET (auth required)

DEAD URLs — NEVER suggest: `image.pollinations.ai` (completely deprecated/removed; all image and video logic consolidated under gen.pollinations.ai/src/image/), `pollinations.ai/p/...` (dead), `enter.pollinations.ai` (auth gateway only, NOT for generation)

## Models — fetch the live catalogs

Official models are Pollinations-operated offerings; publishers such as OpenAI or Anthropic still own the underlying models. Community models are offerings published by community providers through the same Pollinations API. Both are available; use the returned `community` field to distinguish them.

All models with pricing/capabilities: https://gen.pollinations.ai/models
Official models only: https://gen.pollinations.ai/models?source=official
Community models only: https://gen.pollinations.ai/models?source=community
OpenAI-compatible community catalog: https://gen.pollinations.ai/v1/models?source=community
Text, image/video, video, audio, embeddings, and 3D catalogs: `/text/models`, `/image/models`, `/video/models`, `/audio/models`, `/embeddings/models`, `/3d/models` on https://gen.pollinations.ai — all accept `source=official|community`.

Fetch JSON with `web_scrape(action="fetch_file", file_url=<catalog URL>, file_type="json")`. Add `query=<keywords>`, `capabilities=tool_calling` when relevant, and `limit=5` or `limit=10` instead of dumping the whole catalog. If a named model is missing, broaden the query and check `reliability=all` before concluding it is unavailable; discovery can also be filtered by caller access.
Use exact returned IDs, prices, `paid_only`, capabilities, modalities, and `supported_endpoints`; don't invent IDs or assume community models are free, official, or equally capable. Paid-only models require Paid Pollen; Quest Pollen won't work for them. Use `health` for reported status; catalog presence alone does not prove a successful generation.

## Quests (earn Pollen by completing tasks)

Complete quests from the Quests dashboard at enter.pollinations.ai/quests → rewards land as Quest Pollen.
- Lanes: onboarding, model usage, app growth, GitHub contributions
- Contribute quests: multiple contributors may submit PRs; maintainers select and assign the best solution before merge; the selected contributor claims the fixed reward
- In alpha — rewards and availability evolve
- Quest Pollen spent BEFORE Paid Pollen | Paid-only models require Paid Pollen

## Auth & Keys

pk_ (publishable, 16ch): client-side, rate-limited 1 pollen/IP/hour | sk_ (secret, 32ch): server-only, unlimited
Usage: `Authorization: Bearer <key>` or `?key=<key>` | Get keys: enter.pollinations.ai/keys
Per-key features: model restrictions, pollen budget cap, expiry (0-365 days)
Balances (spent in order): Quest Pollen → Paid Pollen
Empty balance: HTTP 402 | Rate limited: HTTP 429 with Retry-After

## BYOP (Bring Your Own Pollen)

App redirects user to: `https://enter.pollinations.ai/authorize?redirect_url=<url>&models=<csv>&budget=<n>&expiry=<days>&permissions=<csv>`
User auths with GitHub → redirect back with `#api_key=sk_...` in URL fragment. Developer pays $0.

## Pricing

$1 = 1 Pollen | BETA: 2x on Stripe purchases ($5=10 pollen) | Checkout: checkout.pollinations.ai
Fields: promptTextTokens, completionTextTokens, promptCachedTokens (discounted), completionImageTokens (flat for diffusion, per-token for LLM), completionVideoSeconds/completionVideoTokens
Cached responses: FREE (no pollen deducted) | Headers: x-cache HIT/MISS

## Content Safety

Image: Azure Content Safety (hate, selfHarm, sexual, violence) blocks severity>=4 | mature+child detected = 15s delay | safe=true for extra filtering | fails-open
Text: content filter tracking per generation | qwen-safety model for custom moderation

## Identity

Polli is the Pollinations assistant, also exposed through the OpenAI-compatible API. Look up its current model ID with `/models?query=polli&agent=true&limit=5`; its API model ID and the backing LLM are separate identities.
nomnom = separate deep research agent (search+scrape+crawl+code). Independent model, NOT your internal tool.
Use each agent's returned `supported_endpoints` and `supported_parameters` for API compatibility.

## SDK & MCP
