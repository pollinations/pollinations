🖥️ Krita Integration

This plugin can run in two ways:

  1. Web app — use this page directly in your browser at krita.pollinations.ai
  2. Native Docker — install the Python plugin to get a Pollinations panel inside Krita with one-click canvas export/import.

Download the Python plugin files below and copy them to your Krita pykrita directory: ~/.local/share/krita/pykrita/ (Linux) or ~/Library/Application Support/Krita/pykrita/ (macOS).
