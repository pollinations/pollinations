Pollinations Quest #15583

Pollinations NPC Dialogue for Roblox

Give Roblox NPCs real conversations powered by Pollinations text models — in a few lines of Luau.

Install in Studio See live API evidence

What you get

One-file ModuleScript

PollinationsNPC.luau gives any NPC a persona and replies to players in chat. No Rojo, no Wally, no build step — copy-paste one file into Studio.

Secrets-first API key

Your Pollinations key lives in Roblox Cloud Secrets and is read only from server scripts via HttpService:GetSecret — never shipped to the client.

Any live text model

Pick any model from the live model list (default openai/gpt-5.4-nano).

Playable example place

A tiny experience with one talking NPC ("Bramble"). Full Studio setup guide included — publish it to get a playable https://www.roblox.com/games/<placeId> URL.

In a few lines of Luau

local ServerScriptService = game:GetService("ServerScriptService")
local PollinationsNPC = require(ServerScriptService.PollinationsNPC)

local shopkeeper = PollinationsNPC.new({
    secretName = "POLLINATIONS_API_KEY",  -- Roblox Cloud Secret
    persona    = "You are Mara, a cheerful potion shopkeeper in a fantasy village.",
    model      = "openai/gpt-5.4-nano",   -- any live text model
})

-- players say "@Mara hello" in chat -> Mara answers
game.Players.PlayerAdded:Connect(function(player)
    player.Chatted:Connect(function(message)
        shopkeeper:Respond(player, message, function(reply)
            print("[Mara]", reply)
        end)
    end)
end)

Install steps

  1. Get an API key at enter.pollinations.ai/keys (sk_* secret key).
  2. In Studio, add a ModuleScript named PollinationsNPC under ServerScriptService and paste luau/PollinationsNPC.luau from the repo.
  3. Create a Cloud Secret POLLINATIONS_API_KEY in Creator Dashboard → your experience → Secrets (local secret for playtesting).
  4. Enable HTTP requests: File → Experience Settings → Security → Allow HTTP Requests.
  5. Run luau/TalkingNPC.server.luau, walk up to the NPC, and type @Bramble hello in chat.

Full details in the repo README and luau/ExamplePlace.md.

      "role": "user",
