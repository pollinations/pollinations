# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] — 2026-09-28

### Added
- PollinationsClient: async text, image, and speech generation via UnityWebRequest
- Support for `/v1/chat/completions` (Bearer token) and `?key=` query param auth
- ModelCatalog integrated: fetch live text, image, and audio model lists
- PollinationsAuth: OAuth 2.0 Device Flow for BYOP (Bring Your Own Pollen)
- PollinationsAuth: browser-based authorization URL for quick sign-in
- Sample scene with demo UI
- Unity Test Runner integration tests
- README with Quick Start, BYOP guide, and API reference
- package.json manifest for Unity Package Manager
