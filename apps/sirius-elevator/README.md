# Sirius Elevator

A cheerful but neurotic elevator that would much rather go up.

## How to Play

Convince the elevator to take you from floor 3 down to floor 1.

```
You: Take me to floor 1.
Elevator: Down? But up is so much nicer! ... Fine, floor 2. [Floor: 2]

You: Keep going.
Elevator: Ground floor? *whimper* [Floor: 1]
```

Say "new game" to restart.
