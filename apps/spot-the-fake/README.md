# Spot the Fake · 真假 AI 猜谜游戏

> 在倒计时内分辨真实照片与 AI 生成图片，练就火眼金睛。
> A browser game where you guess which of two images was generated by AI — before the timer runs out.

纯静态单页应用（HTML / CSS / JS），**零构建依赖**，双击 `index.html` 即可游玩，也可一键部署到 GitHub Pages。

---

## 🎮 玩法说明

1. 每一回合展示两张图片：**一张真实照片**（来自 Wikimedia Commons 的公共领域 / CC 许可图片）和**一张 AI 生成图**（由 [Pollinations AI](https://pollinations.ai) 实时生成）。
2. 在倒计时结束前，点击你认为由 **AI 生成** 的那一张（鼠标悬停卡片可见提示，移动端提示常驻）。
3. 计分规则：
   - 答对：**+100 分**，且连对（streak）每多 1 次额外 **+25 分**（第 2 连 +125、第 3 连 +150 …）。
   - 答错或超时：连击重置为 0，本回合不加分。
4. 每轮结束会揭示答案，并展示：
   - 🤖 **假图破绽**：针对该轮 AI 图主题的观察点提示（水面倒影、文字乱码、重复纹理、手指/窗户细节等）；
   - 📷 **真实照片小知识**：图片主题的科普信息与作者署名。
5. 游戏结束后展示总分、正确率、最高连击，以及**逐回合回顾**（含每轮的破绽提示，方便复盘）。

## ⚙️ 可配置项

- 回合数：5 / 10 / 20（开始界面选择，也可用“快速 5 回合”“挑战 20 回合”快捷按钮）。
- 每轮倒计时：10 / 15 / 20 / 30 秒。

## 🚀 本地运行

**方式一：直接打开（最简单）**

双击 `index.html`，浏览器即可运行。首次游玩需联网（加载真实照片与生成 AI 图）。

**方式二：本地静态服务器（推荐，可用 Service Worker 级缓存）**

```bash
# 任选其一
npx serve polli-spot
python -m http.server 8080 --directory polli-spot
# 然后访问 http://localhost:8080
```

## 🌍 部署到 GitHub Pages

1. 将本目录四个文件推送到一个 GitHub 仓库（例如 `spot-the-fake`）。
2. 进入仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
4. 保存后等待 1–2 分钟，即可通过 `https://<你的用户名>.github.io/spot-the-fake/` 访问。

> 纯静态、无后端、无 Cookie、免登录，满足 GitHub Pages 全部托管要求。

### AI 生成图

- 运行时通过 `https://image.pollinations.ai/prompt/{prompt}?width=800&height=600&seed={seed}&nologo=true&model=flux` 生成；
- `seed` 由 prompt 的 djb2 哈希得到，**同一提示词永远生成同一张图**，保证可复现；
- 图片按 prompt 哈希缓存到本地：优先使用 **Cache API**，不可用时降级到 **localStorage**（存压缩 dataURL），同一提示词只生成一次，节省流量；
- `script.js` 中的 `AI_PROMPTS` 数组预置了 **24 组高质量照片风提示词**（雪山湖、沙漠、瀑布、海滩、银河、极光、樱花、城市天际线、欧洲老城、寺庙、海景小镇、拉花咖啡、夜市、金毛、橘猫、骏马、雄鹰、熊猫、渔夫肖像、咖啡店阅读、复古单车、汉堡、玻璃大厦等），每组均配有专属“破绽提示”。

## 🔧 常见问题

- **AI 图加载不出来？** 需要联网访问 `image.pollinations.ai`。若在线生成失败，游戏会自动使用占位图继续，并在揭示环节明确提示；可稍后重试该回合。
- **缓存不生效？** 浏览器隐私模式或 `file://` 协议下 Cache API 可能受限，脚本会自动降级；不影响游玩。
- **想加更多图片？** 在 `REAL_IMAGES` / `AI_PROMPTS` 数组中追加条目即可，无需改任何逻辑。
