Play, share, hack

Press Play, then drag the canvas: horizontal movement rotates; vertical movement blends the next texture. Number keys 1–9 and arrow keys switch textures. Space pauses. Start paused to choose your own pace.

Load saved Pollinations images or a JSON bank: {"images":[{"url":"https://…/saved.png","caption":"My texture"}]}. Up to 16 images and 32 MB per bank. Public image URLs need CORS enabled; local files are embedded in exports. URLs load once; animation makes no generation calls.

Export keeps the bank and controls together. Only image URLs, captions, and patch settings are kept; credential fields are discarded and common credential parameters in URLs are rejected. Sharing a bank also shares its images and URLs.

Edit patch.js to replace the drawing function. Run from the repository root with python3 -m http.server 8080, then open http://localhost:8080/apps/texture-instrument/. Check the pure functions with node apps/texture-instrument/check.mjs.
