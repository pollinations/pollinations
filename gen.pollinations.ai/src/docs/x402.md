## x402 Payments

Pay per request in USDC through Weft, without a Pollinations API key. Use the usual generation URLs, parameters and response formats with an x402-compatible client.

### How it works

1. Send your request with a unique `Idempotency-Key`, without an API key.
2. If payment is needed, the API returns `402` with a price in `PAYMENT-REQUIRED`. Stable fixed-price models use an exact amount; variable-price models provide a maximum. Your client authorizes it and retries with `PAYMENT-SIGNATURE`.
3. Receive the generated result. The charge follows the model's Pollen price for actual usage, with a $0.001 minimum, and never exceeds your authorization.

Public cache hits are free. Supplying `Authorization` or `?key=` selects API-key authentication instead.

### Current availability

Currently supported: text-only chat (including streaming) with `max_tokens` from 1 to 4096 and text-token pricing, fixed-price single images, and character-priced speech.

Not all models or request formats are supported yet. Other requests, including video, uploads, search and community models, still require an API key. Support depends on being able to quote a spending limit and measure actual usage—not on x402 requiring a particular model or URL.

### Retries and streaming

After a disconnect, retry the same request, including its safety header, `Idempotency-Key` and payment signature. Results and receipts are retained for 30 days. Use a new key for a new generation.

Streaming starts after the initial JSON `402` exchange. Wait for `event: x402.payment` (whose `paymentResponse` field contains the receipt), then `[DONE]`, to confirm success. Failures omit `[DONE]`. Disconnecting does not cancel work; retries replay from the beginning. A payment proxy may buffer streaming output. Paid non-streaming responses and completed replays include the `PAYMENT-RESPONSE` header.

Request and generated bodies are limited to 20 MiB, excluding the receipt. Payment authorization lasts up to 16 minutes.

### Testing

Use `gen.pollinations.ai` with Base USDC in production, or `staging.gen.pollinations.ai` with Base Sepolia test USDC. Use the matching Weft environment and payment network.
