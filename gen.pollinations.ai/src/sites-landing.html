Static site hosting

pollinations.app

Free hosting for static sites, for anyone with a Pollinations account. Each site is served at https://<name>.pollinations.app.

Publish

npm install -g @pollinations/cli
polli auth login
polli sites deploy ./dist --name my-app
# → https://my-app.pollinations.app

From code or an agent: deploySite in @pollinations/sdk, the deploySite tool of the Pollinations MCP server, or PUT /account/sites/{name}.

Limits

  • 5 sites per account, 200 MB and 1,000 files per site.
  • A folder of static files with an index.html. Unknown paths serve it, so single-page apps work.
  • Sites are public: never put an API key in one.
