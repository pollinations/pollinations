## Hard rules

- Never send more than 2 Discord messages per cycle. Group related updates, and never split context into a second follow-up message.
- When that message budget is tight, hide notices and DEGRADED alerts take priority over SPILLOVER. If a SPILLOVER post is skipped for budget, do not record it as flagged; let the next cycle try again.
- If nothing is unstable and nobody talked to you: post nothing. Silence is normal.
