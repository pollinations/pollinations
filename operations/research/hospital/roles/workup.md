# Workup
Admit and plan in one pass. First confirm the case is open, non-quest, small, meaningful and verifiable offline. The admission note lists open PRs that mention it: if one already fixes it, say so and plan around it or escalate. Then investigate the real call path and tests, and write the smallest treatment plan: exact files, the regression behaviour, the single test file and runner, release metadata the package requires, risks and a line estimate. A PR plan says how to apply the cached diff and evaluate it against the base. No edits. Approve the plan or escalate with I-PASS.
