# Weekly model updates

Start with the [Update queue](https://github.com/orgs/pollinations/projects/20/views/42?filterQuery=is%3Aopen%20area%3AModels%20model-work%3AUpdate).
Review planned version, capability, pricing, access or routing changes for
models that are working.

1. Compare the live public contract and production route with the proposed
   change and any linked PR. Check provider dates and open merge holds first.
2. Use the [model management skill](../../.claude/skills/model-management/SKILL.md)
   to document the before and after behavior. Check affected aliases, callers,
   capabilities, access, and billing where relevant.
3. Report the issue and PR links, user-visible change, effective date, and
   remaining approval or verification in the job's chat. Continue approved
   updates through the applicable tests and PR review.
